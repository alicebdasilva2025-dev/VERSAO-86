# LiDire — Versão 76

Correção da exportação de dados pessoais. A exportação agora envia os registros mantidos no estado local do navegador ao endpoint autenticado, além dos dados disponíveis no D1. Foram incluídas categorias como compromissos, tarefas, compras, estudos, treinos, hidratação, alimentação, finanças, objetivos, lembretes, receitas e anotações. Dados de familiares e notificações familiares não são enviados.

O PDF continua sendo gerado pelo recurso de impressão do navegador. A exportação precisa ser validada no ambiente publicado, com a conta e os dados reais.
